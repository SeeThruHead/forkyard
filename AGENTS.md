# Working in this repository

## No AI attribution

Never add AI or agent attribution to anything in this repository: no co-author trailers naming a tool or model, no "generated with" or "generated by" lines, no robot emoji, in commits, files, docs or package metadata. `.githooks/commit-msg` rejects such commit messages and `test/Attribution.test.ts` fails if any tracked file or commit contains them. Enable the hook once per clone with `git config core.hooksPath .githooks`.
